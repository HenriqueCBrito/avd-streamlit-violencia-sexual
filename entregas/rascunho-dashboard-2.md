# Rascunho do Dashboard 2

## Painel estratégico para gestão pública

```text
┌────────────┬────────────┬────────────┬────────────┬────────────┐
│ Ocorrências│ Taxa       │ Cobertura  │ Países com │ Pares      │
│ registradas│ mediana    │ da taxa    │ taxa       │ completos  │
└────────────┴────────────┴────────────┴────────────┴────────────┘

┌────────────────────────────────────────────────────────────────┐
│ Linha da taxa mediana por ano + faixa do intervalo interquartil│
└────────────────────────────────────────────────────────────────┘

┌───────────────────────────────┬────────────────────────────────┐
│ Barras horizontais            │ Barras empilhadas              │
│ 10 maiores medianas           │ taxa disponível × ausente      │
│ mínimo de cinco anos          │ por ano                        │
└───────────────────────────────┴────────────────────────────────┘
```

O painel combina magnitude registrada com cobertura e comparabilidade. Os avisos impedem que a lista de maiores medianas seja tratada como ranking de segurança.
